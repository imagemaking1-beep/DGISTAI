업무이미지DGIST 소개 인포그래픽

업무대충 쓴 이메일 → 깔끔한 업무 메일
아래는 내가 급하게 대충 쓴 이메일이야. 정중하고 읽기 쉬운 업무 메일로 다시 써줘.

④ 캔버스 업무 결과 보고서 → 발표자료(PPT) (업무 · 캔버스)

워드형 보고서가 아니라, 발표용 슬라이드 구조로 나오게 요청합니다. 그대로 구글 슬라이드·PPT로 옮겨 씁니다.

업무캔버스업무 결과 보고서 (발표자료용)
업무 결과 보고를 위한 '발표자료(프레젠테이션)'를 캔버스로 만들어줘.
A4 문서가 아니라, 한 장 한 장이 슬라이드가 되도록 '슬라이드 단위'로 구성해줘.

[구성] 슬라이드 6~8장, 각 슬라이드는 아래 형식으로
- 슬라이드 제목(한 줄, 핵심 메시지)
- 핵심 내용 3~4개 불릿(각 한 줄, 수치·근거 포함)
- (해당되면) 표나 도식으로 표현하면 좋은 부분은 '[표: …]' '[그래프: …]'로 표시
- 하단에 발표자가 말할 한 줄 스피커 노트

[슬라이드 순서]
1) 표지(보고 제목·부서·날짜) 2) 배경·목적 3) 추진 내용
4) 핵심 결과(수치 중심) 5) 성과·시사점 6) 이슈·개선점 7) 다음 계획 8) 요약

[톤] 전문적인 비즈니스 보고체, 간결하게. 과장 없이, 근거 있는 표현으로.
[예시 주제] 신입 OJT 1주차 진행 결과 보고 (참석률·만족도·주요 피드백 포함)
💡 PPT로 바로 쓰기  나온 슬라이드 구조를 구글 슬라이드 새 프레젠테이션에 붙여넣으면 발표자료가 됩니다(구글 계정 연동 → 팀과 바로 공유·편집). 더 빠르게 하려면 “이 내용을 구글 슬라이드로 만들 수 있게 슬라이드별 제목·본문·발표노트로 정리해줘”라고 이어서 요청하세요. (제미나이 노트북의 ‘슬라이드 자료’ 기능으로도 발표본을 만들 수 있어요.)

업무캔버스신입 환영회 안내 HTML
역할 부여: 당신은 트렌디한 감각을 지닌 시니어 UX/UI 디자이너이자 프론트엔드 개발자입니다.

[디자인 및 UI/UX 핵심 요구사항]
- 전체 무드: DGIST의 시그니처 컬러(딥블루 & 스카이블루)를 활용해 신뢰감 있고 산뜻한 분위기를 연출하세요. 배경에는 은은한 블루 계열의 그라데이션을 적용해 단조로움을 피해주세요.
- 히어로 섹션(최상단): "DGIST의 새로운 내일, 여러분과 함께 시작합니다" 같은 감성적인 환영 문구가 크게 들어가고, 페이지 로드 시 텍스트가 부드럽게 나타나는 페이드인(Fade-in) 애니메이션을 넣어주세요.
- 정보 전달 방식(단순 표 지양): 행사 정보는 딱딱한 표 형태를 벗어나, 아이콘(이모지 등)을 활용한 '모던 카드(Card) 레이아웃'이나 '글래스모피즘(Glassmorphism, 반투명 효과)' 스타일로 예쁘게 배치해주세요.
- 타이포그래피: 가독성이 뛰어난 폰트(Pretendard 등)를 사용하고, 자간과 행간을 넉넉하게 주어 여백의 미를 살려주세요.

소스 검색업무① 주제로 웹 소스 빠르게 검색
'AI 기반 스마트 연구 환경 및 디지털 행정 혁신 기획'을 주제로 관련 자료를 검색해서 소스로 추가해줘.
- 국내외 연구기관·공공기관의 사례, 핵심 기술(AI·데이터·자동화), 기대효과 중심으로

* 자료에 없는 내용은 지어내지 말고 '자료에 없음'으로 표시할 것

Idea to App — 3단계

① 아이디어(불편함): 연차 계산기, 회의실·장비 예약, 설문 집계, 예산 대시보드 … “이런 게 있으면 좋겠다”  →  ② 설명: 무엇을 · 어떤 화면 · 안 만들 것  →  ③ 만들기 · 배포 · 테스트. 핵심은 완벽한 코드가 아니라 ‘명확한 설명’.

먼저 무엇을 만들지 고르기
회의실·장비 예약 보드 (추천) 연차·근무일 계산기 설문 집계 도구 예산 대시보드

완성 예시 — 회의실·장비 예약 보드 (오늘 만들 앱)

오늘 만들 앱의 완성본입니다. 먼저 열어보고, 아래 STEP대로 직접 만들어요.

완성 예시회의실·장비 예약 보드 (AI 스튜디오)열어보기 ↗
시간대×대상 표로 예약 현황을 보고, 오른쪽에서 새 예약을 등록·취소하는 앱.

STEP 1 · 예약 보드 만들기 (빠르게 한 번에)

STEP 1회의실·장비 예약 보드
‘회의실·장비 예약 보드’ 웹앱을 빠르게 한 번에 만들어줘(동작하는 최소 버전).
- 상단: 날짜 선택 / 시간대(09~18시) × 대상(대회의실·소회의실·세미나실·공용 노트북·빔프로젝터)을 표로 예약 현황
- 오른쪽: ‘새 예약 등록’(대상·시작·종료·예약자 이름) + ‘오늘 예약 목록’
- 데이터는 Cloud Firestore에 저장(로그인 없이), 예시 예약 2건을 미리 넣어 화면이 바로 보이게
- 밝은 배경·네이비 글자·파랑 포인트·둥근 카드, 모바일 대응, 설명 없이 코드만

STEP 2 · 기능 하나씩 붙이기

한꺼번에 X — 하나 붙이고 눌러보고 다음.

STEP 2예약 로직 추가
① 표의 빈 시간대를 클릭하면 그 시간으로 ‘새 예약 등록’이 자동으로 채워지게
② 같은 대상·같은 시간의 중복 예약은 막고 안내 메시지 표시
③ ‘오늘 예약 목록’에서 ‘취소’ 버튼으로 예약 삭제
④ 예약 칸을 대상별 색으로 구분해 한눈에 보이게

STEP 3 · 인터넷에 올리기(배포)

  1. AI 스튜디오 → 공유 → 게시 (무료 등급 앱 2개까지, 실제 결제는 안 함)
  2. 배포 대기(몇 분·정상) → 인터넷 주소가 나오면 새 창에서 열기
  3. 배포 링크를 휴대폰으로 열어 모바일에서도 잘 보이는지 확인
🔒 만들기 전 꼭 확인
